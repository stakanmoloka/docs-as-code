# Model Card

## Общая информация

**Название модели:**  
`keras-io/collaborative-filtering-movielens`.

**Источник:**  
[Hugging Face Hub](https://huggingface.co/keras-io/collaborative-filtering-movielens).

**Автор / организация:**  
Keras. На странице модели указано, что полная благодарность за исходный пример принадлежит Siddhartha Banerjee.

**Задача модели:**  
Коллаборативная фильтрация для рекомендаций фильмов. По пользователю и фильмам, которые он высоко оценивал, модель предсказывает нормализованную оценку еще не просмотренного фильма в диапазоне от 0 до 1.

**Язык:**  
Не указано авторами модели. Модель использует табличные данные об идентификаторах, оценках и жанрах, а не естественный язык.

## Использование в проекте

В рекомендательной системе фильмов модель применяется для ранжирования фильмов для конкретного пользователя. После получения идентификатора пользователя и его предпочтений через `POST /recommendations` сервис использует историю оценок пользователя для расчета релевантности фильмов. Фильмы с наибольшими оценками формируют список рекомендаций, который возвращается API.

## Входные данные

Идентификатор пользователя, идентификаторы фильмов и сведения о ранее поставленных пользователем оценках. В данных обучения также используются жанры фильмов.

## Выходные данные

Прогноз оценки для фильма, который пользователь еще не смотрел, в диапазоне от 0 до 1. В проекте этот результат используется как `score` для сортировки фильмов.

## Метрики качества

Авторы приводят значения функции потерь при обучении и валидации. На пятой эпохе указаны train loss `0.608` и validation loss `0.609`. Метрики ранжирования, например Precision@K или NDCG, авторами не указаны.

## Ограничения

- Модель предназначена только для рекомендаций фильмов; использовать ее для иных предметных областей нельзя.
- Результат зависит от истории оценок пользователя. **Потенциальное ограничение для нашего проекта:** для нового пользователя без истории модель не сможет сформировать персональную рекомендацию с той же надежностью.
- Авторы не указали поддержку языков и качество на русскоязычных каталогах. **Потенциальное ограничение для нашего проекта:** названия и жанры в ином языке или формате необходимо отдельно проверять.
- Авторы не приводят метрики качества ранжирования. Поэтому качество списка рекомендаций на нашем каталоге нужно измерить отдельно до использования модели.

## Не рекомендуется использовать

Не следует использовать результат модели как гарантию того, что фильм понравится пользователю. Модель не предназначена для принятия юридически значимых, медицинских, финансовых или иных важных решений и не должна самостоятельно ограничивать доступ пользователя к контенту.
