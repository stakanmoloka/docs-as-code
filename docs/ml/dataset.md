# Data Sheet

## Общая информация

**Название датасета:**  
`pinecone/movielens-recent-ratings` (MovieLens User Ratings).

**Источник:**  
[Hugging Face Datasets](https://huggingface.co/datasets/pinecone/movielens-recent-ratings). Исходные рейтинги получены из [MovieLens 25M](https://grouplens.org/datasets/movielens/25m/).

**Назначение:**  
Набор предназначен для построения и оценки систем рекомендаций фильмов на основе оценок пользователей.

## Состав данных

**Объем:**  
Около 1 миллиона оценок для примерно 10 000 недавних фильмов от более чем 30 000 пользователей.

**Тип данных:**  
Табличные данные; язык названий фильмов в карточке датасета указан как английский.

**Основные поля / признаки:**  
`user_id` — идентификатор пользователя; `movie_id` — идентификатор фильма; `rating` — оценка; `title` — название фильма; `imdb_id` — идентификатор IMDb; `poster` — URL постера.

## Получение данных

Набор формируется из MovieLens 25M. Скрипт датасета выбирает недавние фильмы, объединяет сведения о фильмах и рейтингах, а также добавляет ссылки на постеры.

## Предобработка

- выбраны фильмы с `imdbId` не менее `2000000`;
- оставлены пользователи и фильмы, которые встречаются более двух раз;
- исходные идентификаторы фильмов и пользователей преобразованы в последовательные числовые индексы;
- данные разделены на обучающую и тестовую выборки: 90% и 10%; разбиение стратифицировано по фильму, `random_state=0`.

## Ограничения

- В наборе представлены только оценки и метаданные фильмов из MovieLens; он не отражает весь каталог фильмов и вкусы всех зрителей.
- Карточка датасета указывает английский язык, поэтому применимость к русскоязычному каталогу необходимо проверять отдельно.
- Фильмы и пользователи с очень малым количеством взаимодействий исключены при предобработке. Поэтому набор хуже представляет редкие фильмы и новых пользователей.
- Ссылки на постеры являются внешними ресурсами и могут перестать быть доступными.

## Использование в проекте

Датасет подходит для оценки и потенциального дообучения рекомендательной системы: оценки пользователей формируют историю взаимодействий, а данные о фильмах используются для отображения результатов. Перед использованием в проекте идентификаторы и каталог фильмов нужно сопоставить с данными собственного сервиса.
