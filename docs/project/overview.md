# Рекомендательная система фильмов

Сервис автоматически подбирает и предлагает фильмы на основе интересов, предпочтений и истории просмотров пользователя.

Основные пользователи:
- пользователь;
- администратор системы.

Основные функции:
- указание предпочтений пользователя;
- анализ интересов и истории просмотров;
- формирование персональных рекомендаций фильмов;
- просмотр рекомендованных фильмов.

## Комплект документации

1. Описание проекта. Предназначено для пользователей и разработчиков, чтобы объяснить назначение рекомендательной системы фильмов и ее основные возможности.

2. Требования к системе. Предназначены для разработчиков, чтобы определить основные функции системы и требования к ее работе.

3. Архитектура системы. Предназначена для разработчиков, чтобы описать структуру системы и взаимодействие ее компонентов.

4. Документация API. Предназначена для разработчиков, чтобы описать способы взаимодействия с системой, получения информации о фильмах и рекомендаций.

5. Документация ML-модели. Предназначена для разработчиков, чтобы описать алгоритм формирования рекомендаций на основе предпочтений пользователя.

6. Руководство пользователя. Предназначено для пользователей, чтобы объяснить, как указывать свои предпочтения и получать рекомендации фильмов.
