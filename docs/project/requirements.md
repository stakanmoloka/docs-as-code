# User Stories

### US-01. Указание предпочтений

Как пользователь,  
я хочу выбирать интересующие меня жанры фильмов,  
чтобы система могла учитывать мои предпочтения при формировании рекомендаций.

**Критерии приёмки:**
- пользователь может выбрать один или несколько жанров;
- система сохраняет выбранные предпочтения;

### US-02. Получение рекомендаций

Как пользователь,  
я хочу получать персональные рекомендации фильмов,  
чтобы находить фильмы, соответствующие моим интересам.

**Критерии приёмки:**
- система анализирует предпочтения пользователя;
- система формирует список рекомендованных фильмов;

### US-03. Оценка фильмов

Как пользователь,  
я хочу оценивать просмотренные фильмы,  
чтобы система могла улучшать рекомендации на основе моих оценок.

**Критерии приёмки:**
- пользователь может поставить фильму оценку от 1 до 10;
- система сохраняет оценку пользователя;
- система учитывает оценки при формировании новых рекомендаций.


# Use Case

### UC-01. Получение рекомендаций фильмов

**Актор:** пользователь.

**Цель:** получить персональные рекомендации фильмов.

**Предусловие:** пользователь указал свои предпочтения по жанрам фильмов.

**Основной сценарий:**

1. Пользователь открывает раздел рекомендаций.
2. Система передаёт предпочтения пользователя ML-модели.
3. ML-модель подбирает фильмы на основе предпочтений.
4. Система получает список рекомендованных фильмов.
5. Пользователь видит список рекомендаций.

**Альтернативный сценарий:**

Если модель не может сформировать рекомендации, система сообщает об ошибке и предлагает пользователю просмотреть популярные фильмы.

**Результат:** пользователь получил персональные рекомендации фильмов или список популярных фильмов.
