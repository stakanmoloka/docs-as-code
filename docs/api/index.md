# API

API предоставляет доступ к функциям рекомендательной системы фильмов.

## Основные операции

- `POST /recommendations` — сформировать персональные рекомендации фильмов;
- `GET /recommendations/{userId}` — получить рекомендации пользователя;
- `GET /movies/{movieId}` — получить информацию о фильме.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
